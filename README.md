# Legend of the Lead

A retro-style arcade game where you play as a salesperson at a trade show, trying to capture leads.

## How to Play

- Use the **arrow keys** to move your character around the trade show floor.
- Intercept the other characters (attendees) to "capture" them as leads.
- Once an attendee is captured, they become a "lead" and will automatically head for the nearest exit.
- Your goal is to capture as many leads as possible.
- The game is over if you miss too many potential leads.

## How to Run

1. Clone or download this repository.
2. Open the `index.html` file in a web browser.

## Game Files

- `index.html`: The main HTML file for the game.
- `style.css`: Contains the styles for the game's appearance.
- `game.js`: The core game logic, including player movement, attendee AI, and rendering.

## Technologies Used

- HTML5 Canvas
- CSS3
- JavaScript (ES6)
